# Cannot Convert a PDF

A tiny Node/TypeScript program for the make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert". It writes one satirical sentence about lawmakers who regulate the internet but cannot convert a PDF to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 320 characters.

Entry line:

> The committee that regulates the internet cannot convert a PDF, yet it will decide what your AI is allowed to say about it.

Run it with: `node main.ts`
